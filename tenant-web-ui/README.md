# TenantHub Portal (tenant-web-ui)

The tenant-facing portal for TenantHub: each tenant manages its own users, roles, departments,
projects and devices, and views its login and operation logs.

Built with Vue 3, TypeScript, Element Plus, Pinia, vxe-table and Vite.

## Development

```bash
pnpm install
pnpm dev            # http://localhost:8555/tenant/  (API: VITE_BASE_API in .env.development)
```

## Build

```bash
pnpm build:stage    # staging   (.env.staging)
pnpm build:prod     # production (.env.production), output in dist/
```

The production build is served at the site root (`/`) with the API proxied at `/api`
(see the root `nginx.conf`).

## Checks

```bash
npx vue-tsc --noEmit   # type check
pnpm lint
pnpm test
```

## Notes

- Dates from the API are UTC; `src/utils/utc-time.ts` converts them to the browser's time zone
  in the HTTP interceptors.
- Addresses use the India state → district → sub-district picker (`src/components/SearchIndiaArea`),
  backed by `src/assets/IndiaArea.json` (generated by `scripts/india-area/generate.mjs`).
